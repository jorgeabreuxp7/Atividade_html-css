# 🐠 Mundo dos Peixes

Um site simples em HTML e CSS para apresentar diferentes espécies de peixes de aquário e as suas características principais.

Projetado com uma estrutura básica (cabeçalho, menu lateral, e rodapé) e estilizado em tons de azul.

---

## 📂 Estrutura do Projeto

O projeto está organizado com as páginas HTML e CSS numa pasta dedicada a ambas:

```
projeto/
│
├── css/
│   └── style.css
│
└── html/
    ├── index.html
    ├── palhaco.html
    ├── betta.html
    ├── dourado.html
    └── neondutra.html
